# Track A Phase 5: automated screening

Executed locally on 2026-11-20 using only deterministic Python rules. The frozen Phase 4 processed file, manifest, grouped split and 30-ID queue matched their recorded SHA-256 values before screening. No source file, split or human decision was changed. The versioned `screening_v3.jsonl`, manifest and 1,000-ID review plan are under restricted, Git-ignored `ml/data/phase5/`. They contain hashed IDs, source labels and machine codes, **no narrative text**. A cached run verifies all input and output hashes and refuses changed results. No package or model was downloaded; no network or LLM request is made by the screening module.

All **1,000** OpenCity candidates were screened. The machine status is `screened` for each. The full source taxonomy remains 31 named categories and one unlabeled `NULL` sentinel; no UP category or department mapping was created. The source category is retained independently of every machine suggestion. Screening output SHA-256: `11aa2ef5804fe520736b59c50fb80f5c2e2aa61f454b460f58c71a76486abf08`; review-plan SHA-256: `33faee2fec7d77e40ca11c1f0f1fcff0dfee3984d2cbe2a8ae8a25dac7cbf213`.

Rules combine prior privacy flags with direct-pattern checks, possible person/name cues, indirect place and household cues, unusual numbers, basic narrative-quality cues, title/description pilot-topic conflict, two static pilot-keyword sets, script/lexical language hints, exact/template and high token-overlap matching, and a weak same-title/date/category cross-language candidate check. Every suggestion has a rule version and evidence codes. Confidence reflects pattern strength, **not** a calibrated probability. The rules cannot prove anonymity, authorship, language or publisher-label correctness. Semantic paraphrases and translated variants with different titles may escape these rules; no approved offline multilingual model was available, so they remain for human review.

The machine artifact sets `training_eligibility=false` and contains no human decision fields. Human submissions live only in the separate credentialed review store, which has not been initialized. Even a future human-cleared record still needs an owner-approved training protocol.
