Reviewed 2026-11-20. No civic dataset was downloaded during this review. Source pages and metadata were read without collecting individual complaint records. This report separates citizen narratives from issue labels, staff notes, and unverified third-party uploads.

## Source-label crosswalk proposal

These are lexical research candidates only. They are **not** approved UP routing rules and do not create new labels for any record. Keep the source-provided category and agency in separate fields, then have human reviewers approve each crosswalk on examples.

| Source label visible in publisher documentation | Proposed NagrikOS category | Ambiguity to review |
| --- | --- | --- |
| BBMP `Road Maintenance` / `Potholes` | Roads & Infrastructure | Road owner and urban/rural jurisdiction determine the actual desk. |
| BBMP `Solid Waste` / `Garbage Dump` | Sanitation & Waste | Waste collection, drainage and sewerage need separate service ownership. |
| BBMP `Electrical` / `Street Light Not Working` | Electricity **or** Roads & Infrastructure | Streetlight poles may be municipal assets or distribution-company assets; no automatic department. |
| Janaagraha `category_title` / `sub_category_title` | **Unmapped pending field-value review** | The field names are documented, but source category values were unavailable due HTTP 403. No synthetic crosswalk was invented. |

The existing [UP mapping review](LABEL_MAPPING_REVIEW.md) identifies additional ambiguity in water, education, welfare, safety and land matters. Bengaluru labels and agencies cannot establish UP responsibility.

## Access and approval gates

1. Ask OpenCity/Janaagraha for a working public CKAN API or field-selected export of the 2019–2022 log. The desired export contains only case ID, title/description, category/subcategory, agency, creation date and status; exclude address, coordinates, location, and person metadata at source. [CKAN's DataStore documentation](https://docs.ckan.org/en/latest/maintaining/datastore.html) describes bounded `limit` and `fields` requests.
2. If an export is supplied, verify actual narrative content, attribution/license, personal-data incidence, duplicate templates, category quality and language distribution before classifying any row as usable.
3. Obtain authoritative UP department/jurisdiction approval before mapping source categories to an operational route. No NagrikOS app mapping was changed here.
